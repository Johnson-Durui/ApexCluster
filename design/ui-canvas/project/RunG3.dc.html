架构说明手册：本地个人记账与预算工具

文档 v1 · 待评审 · 2026-10-12 · 读者：老板、用户方

草稿：尚未经过评审确认（G3）。
本文档写于最小 MVP 构建之前：验收标准已先对齐；MVP 验证后，执行结果由程序根据执行日志自动填写。

1. 要解决的问题

在一台 Windows 电脑上记账、导入银行 CSV、按月设置分类预算并查看汇总；数据只保存在本机。REQ-1

2. 已确认的框架

选择 C1 · 本地 Node 服务 + SQLite + React 单页。一个本地 Node.js 进程同时提供接口和页面，数据存在 SQLite 单文件中，备份即复制文件。G2 · C1

3. 模块与职责

模块职责来源
浏览器界面记账、预算设置、图表C1-M1
本地 API 服务校验输入、计算预算、读写数据C1-M2
账单导入解析 CSV 并去重C1-M3
数据库交易、分类、预算持久化C1-M4

4. MVP 范围与验收

范围内：手动记账、导入 CSV 并去重、当月预算汇总。验收项 AC1–AC3，其中 AC3 由你在 G4 人工确认。SPEC-C1
