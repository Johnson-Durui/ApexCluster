评审流程

新建评审
  1. G1
    回答问题两位模型提出带选项的澄清问题，你回答或采用默认。
  2. G2
    确认框架查看规则结论、评分依据和分歧，确认候选与 MVP 范围。
  3. G3
    确认文档确认架构说明手册与开发文档，构建才会开始。
  4. G4
    验收 MVP以 Sol 的执行日志和你的人工结果为准接受或重试。
  5. G5
    确认 PRD依据真实结果撰写的 PRD 由你确认或修订。
