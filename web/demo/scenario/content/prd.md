# RoomDesk 团队会议室预约 · 产品需求文档（PRD）

版本 1.0 · 随需求契约第 1 版冻结

## 1. 原始需求（逐字）

> 帮我做一个团队会议室预约小工具：先出 PRD 和技术架构，再完成可运行的 Web 应用和自动化测试。需要支持按楼层筛选、冲突检测和 iCal 导出。

## 2. 目标

1. 员工在一个页面内看清“哪间会议室什么时候空”，并在 30 秒内完成一次预约。
2. 预约当下就发现冲突，而不是开会时才发现两拨人撞在同一间屋子。
3. 预约结果能一键放进自己的日历（Outlook、苹果日历、各类日历应用都能读的 .ics 文件）。
4. 交付一个不依赖后端和第三方库、打开即用、带自动化测试的 Web 应用。

## 3. 用户

| 角色 | 场景 |
|---|---|
| 会议组织者 | 找一间合适人数的会议室，避开已有会议，预约后加入日历 |
| 参会者 | 查看某层某间会议室当天的安排 |
| 行政 / 前台 | 按楼层浏览全天占用情况，导出当天预约 |

## 4. 范围

- 3 个楼层、8 间会议室（名称、楼层、容纳人数、设备）。
- 日程板：会议室为行、小时为列，显示 08:00–21:00 的当天预约，可切换日期。
- 预约表单：会议室、日期、开始、结束、会议主题、预约人。
- 规则：15 分钟网格；整段在 08:00–21:00 内；开始早于结束；单次最长 4 小时。
- 冲突检测与建议：实时提示冲突，给出最近空闲时段和同楼层空闲会议室。
- “我的预约”列表：下载单场 .ics、取消预约。
- iCal 导出：单场或整天，符合 RFC 5545。
- 本地持久化：浏览器 localStorage。
- 首次打开带明确标注的示例数据。

## 5. 验收标准

| 编号 | 验收标准 |
|---|---|
| AC-01 | 页面提供“全部楼层”和 3 个楼层页签；选中某层后日程板只显示该层会议室，顺序与配置一致。 |
| AC-02 | 日程板按会议室行、小时列展示所选日期的预约，时间轴覆盖 08:00–21:00，可切换前一天、后一天和今天。 |
| AC-03 | 时段必须对齐 15 分钟、落在 08:00–21:00 内、开始早于结束、时长不超过 4 小时；08:00 开始和 21:00 结束允许；不合规时显示具体原因且不能提交。 |
| AC-04 | 预约必须指向存在的会议室，会议主题必填且不超过 40 字，预约人必填；日期必须是真实存在的日期。 |
| AC-05 | 同一会议室、同一天的两个时段按半开区间 [开始, 结束) 判断重叠：有交集即冲突，首尾相接不冲突，不同会议室或不同日期不冲突，编辑自身不与自己冲突。 |
| AC-06 | 填写表单时实时显示冲突（与哪场会议、时间、预约人），存在冲突时不能提交；提交时再次检查，冲突的预约不会写入。 |
| AC-07 | 冲突时给出同一会议室内离原开始时间最近、时长相同的空闲时段，距离相同优先顺延，可一键采用；同时列出同楼层同时段空闲的会议室，可一键切换。 |
| AC-08 | “我的预约”列出本人预约（含标注为“示例”的预置预约），每项可下载 .ics、可取消；取消需要二次确认。 |
| AC-09 | 可导出单场或整天的 .ics：包含 VCALENDAR、VEVENT、UID、DTSTAMP（UTC）、DTSTART/DTEND（默认 TZID=Asia/Shanghai 并附 VTIMEZONE，另支持 UTC 形式）、SUMMARY、LOCATION、DESCRIPTION；文件在浏览器内生成并下载。 |
| AC-10 | iCal 文本值转义反斜杠、分号、逗号和换行；内容行超过 75 字节时折行，续行以空格开头，不拆开多字节字符；所有行尾为 CRLF。 |
| AC-11 | 预约保存在 localStorage（键 `roomdesk:v1:state`），刷新后仍在；存储不可用或数据损坏时页面照常可用并提示，不合法记录被丢弃。 |
| AC-12 | 首次打开显示带“示例数据”标注的 3 层 8 间会议室及今天和下一个工作日的预约，示例可删除并可一键恢复；页面只用相对路径，可部署在任意子路径；1280×720 下无横向滚动，375 px 宽度可用；`npm test` 全部通过。 |

## 6. 不在本期范围

- 用户登录、权限和多人实时同步（数据只在当前浏览器）。
- 服务端存储、并发锁和审批流程。
- 周期性会议（RRULE）、跨天会议和夏令时时区。
- 邮件或即时消息通知、参会人邀请（.ics 中不写 ATTENDEE / ORGANIZER）。
- 与现有日历系统的双向同步。

## 7. 假设与约束

- 所有会议室位于同一时区 Asia/Shanghai（UTC+08:00，无夏令时）。
- 一次预约只占一间会议室，不跨天。
- 不引入任何第三方运行时依赖；测试只用 Node.js 自带的 `node:test`。
